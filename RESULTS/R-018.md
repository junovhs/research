# R-018 · Water-quality sparse-query challenge: exact backward identity versus certified suffix

**Date:** 2026-10-13 PDT / 2026-10-14 UTC. **Track: EXPLORATORY: YES; PREREGISTERED: NO; POD: NO; NOVELTY UNVERIFIED. Evidence: REPORTED**, one source-bound executable run using a locally reconstructed schema-2 guard, with independent exact-Fraction cases but no external independent reproduction. **Decision: PARK** R-013/R-014-style transport omission engineering for *linear* quality-transport tasks unless a guarantee-matched specialist gap is established. ## Question, real application and decision gate

EPA's [EPANET 2.2 analysis-algorithm manual](https://usepa.github.io/EPANET2.2/12_analysis_algorithms.html) models time-dependent advection, tank mixing, mass conservation, and first-order chlorine decay. EPA's [TEVA-SPOT toolkit](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P100U5A5.txt) models many contamination scenarios for sensor placement; a published [large-utility case](https://www.epa.gov/sites/default/files/2017-10/documents/pwd_report_locating_owqm_stations_using_teva-spot.pdf) reports that a combined network of more than 100,000 pipes was too large for direct full-system design analysis, so a staged subnetwork strategy was used. Thus, repeated contamination *scenario* computations are consequential. But TEVA-SPOT typically needs **detection times and impacts across many candidate sensors**, not simply one terminal output, so the sparse-output premise cannot be presumed. The exact historical algorithm, source layouts, flow histories, and required error tolerance are not available in this probe.

The narrowly stated **conditional** use case is: fixed precomputed hydraulics or mixing coefficients across many candidate pollutant releases; predict one sensor concentration at a given time, with binary64 numerical accuracy or a separately stated enclosure. Hydraulic simulation/setup and data retrieval would have to be charged in any real cost study. The **strongest specialist challenge** is not full forward replay: [Shang, Uber and Polycarpou (2002), Particle Backtracking Algorithm for Water Distribution System Analysis](https://ascelibrary.org/doi/10.1061/%28ASCE%290733-9372%282002%29128%3A5%28441%29), which already proposes a direct input-output water-quality backtracking model; [Wagner and Neupauer (2013)](https://doi.org/10.1061/9780784412947.094) also apply adjoint/backtracking to contamination-source inference. This study reconstructs a basic transpose-adjoint identity for a **surrogate**, not those papers' exact implementations. Their closest published capability substantially weakens an originality/economic case for R-014 in the linear passive-species domain.

**Decision-changing prediction:** in a reused linear quality-transport operator, one precomputed adjoint propagator for one sensor/time may answer many sparse source scenarios more cheaply than independently recomputing an admissible recent suffix. **Falsifier:** unequal exact-discrete outputs; materially worse *all-in* adjoint cost than suffix across realistically queried cases; or an important nonlinear/complex-transport output capability not covered by the published specialist. The strongest unrelated direction remains a truly nonlinear, sparse exact-discrete output with input access and a guaranteed comparator; do not promote this surrogate by itself.

## Exact discrete surrogate and proof (not an EPANET numerical equivalence claim)

On a directed periodic ring of D sites, let x(0)=0 and for t=0,…,N−1 set

    x(t+1,i) = a(t) x(t,i) + l(t) x(t,i−1) + r(t) x(t,i+1) + b(t,i),
    a(t)=rho*(5/8+v(t)), l(t)=rho*(1/4−v(t)), r(t)=rho/8,
    v(t)=((t mod 11)−5)/256,
    0 <= b(t,i) <= 1−rho,     0 < rho <= 1.

Here rho is chosen per experiment; coefficients are nonnegative, a+l+r=rho. The state is a **linear, finite-dimensional, time-varying, graph-local discrete transport surrogate**. It is only *motivated* by mixing plus first-order decay in EPANET. No real hydraulic traces, tanks, junction direction changes, dispersive mixing, or physical calibration are represented. An injection scenario has ten noncolliding input events at timestamp/site pairs (generated by a documented seeded PRNG) and zero elsewhere; batches share the same transport coefficients and target output `x(N,41)`.

Let A(t) be the sparse transport matrix and e_j the chosen sensor basis vector. For an arbitrary x(0) and source sequence b, define `w(N)=e_j` and `w(t)=A(t)^T w(t+1)`. Then by telescoping,

    e_j^T x(N) = w(0)^T x(0) + sum_{t=0}^{N−1} w(t+1)^T b(t).

This is an **exact identity in rational arithmetic**, not a new mathematics claim. For known source event locations, compute each needed `w(t+1,i)` in one backwards sweep and answer every scenario by a sparse dot product. Reusing the same backtracking weights is allowed only when its transport coefficients, query time and sensor are genuinely reused. Do **not** call this the actual EPANET backtracking implementation.

Nonnegative inputs and the row sum rho imply `[0,1]^D` is invariant from x(0)=0. A suffix solve starting at the zero vector at time N−K and applying only inputs in that suffix has a valid lower endpoint for the actual nonnegative full-history output; dropping the unknown earlier state causes at most `rho^K` error in sup norm. Thus the closed interval `[suffix, suffix+rho^K]` contains the chosen exact-discrete output. Its uniformly valid admission condition is `rho^K <= eps`. This is a **crude, rigorously derived unknown-prefix bound in exact real arithmetic**, not a proof about finite-precision floating-point rounding. It does not exploit individual historical injection patterns, nor spatial omission; an adaptive R-013 interval may be tighter. The implemented binary64 suffix is independently compared with the full binary64 trajectory, not claimed as finite-arithmetic certified.

**Non-forgetting obstruction:** when rho=1, b=0 and transport is a pure cyclic shift, `x(N,j)=x(0,j−N mod D)`. Starting a suffix from the full invariant box cannot reduce initial uncertainty at all. With unrestricted exogenous injections on a pure shift, a selected output can depend on one arbitrary input bit from each of N times along its backward characteristic; absent an input index or precomputation, exact worst-case query requires reading all N bits. This scoped adversary does *not* refute input-specific forgetting on contracting cases or all specialized solvers.

Cost per query in an actual scenario ensemble must include all previously executed hydraulic computations, file/index construction, source generation and reading, quantity of sensor/times, failed certificates and exact fallback; realistic scaling can reverse this result. A space-*and*-time input-specific R-014-style interval patch could beat the simple full-width suffix for Q=1; **no R-014-like patch was implemented here**, so that competitor's relative performance is unknown. Most importantly, exact transpose output is not a guarantee-matched interval-certified answer in floating point: use directed interval/ball arithmetic or an independent error budget if the application truly requires a rigorous enclosure.

## Decision, boundaries, opportunity cost and novelty

**Decision: PARK** R-013/R-014 engineering as a generic replacement for existing linear passive quality-transport specialists. The specialist already has an exact mathematical input/output representation, and a direct 24-case exact-Fraction check plus 144 binary64 forward/adjoint cross-checks support that understanding. The simulated repeated-scenario regime clearly benefits from precomputed backward coefficients, but its numerical time ratios are exploratory and Python-specific. We have **not** shown that EPANET itself runs faster with adjoints, that either algorithm yields a physical chlorine prediction within eps, or that an R-014 spatially local implementation cannot outperform a specialist for single queries.

**What would change the decision:** source a real EPANET scenario dataset plus saved hydraulics and a precisely documented *few-sensor/few-time* query contract, compare EPANET/particle-backtracking (not merely dense forward simulation) under same guarantee and full data-access costs, and test a mathematically *nonlinear* reactive model with selective localized error control. If the input/output budget or new capability does not survive that contract, close this application line and search for a genuinely distinct mathematical shortcut. P-051's separate hard chart problem and the parked R-015/R-017 work do not automatically become the next direction. No new originality claim; ingredients (linear adjoint, water-quality backtracking, finite-history contraction) are already known.

**Provenance limits:** No independent external reviewer, no held-out prospective preregistered claim, no original historical R-014 execution recovery, no EPANET run, no continuous PDE/physical error enclosure, no float-rounding certificate and no formal POD. `POD: NO`. **MAP.md unchanged:** applying an already published backtracking identity to an existing conditional research direction neither demonstrates a distinct new mathematical branch nor closes R-013's general line. The live state is the priority source.
