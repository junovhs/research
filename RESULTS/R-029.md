## Question and task/value gate

Can a selected terminal composite concentration in a nonlinear reaction/transport model be computed from initial data and a shared linear adjoint, *without evaluating nonlinear reaction histories*, when the two species have unequal transport? This tests the assumption driving [R-019](R-019.md), rather than implementing EPANET. The [EPA EPANET-MSX 2.0 manual](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10188CK.TXT) motivates the question: multi-species transport, immobile wall versus bulk species, and optional species-specific dispersion. Previous R-019 assessed a credible repeated terminal-sensor design subproblem; the complete real workload, query frequency, hydraulic/data access, accuracy requirement and specialist economics **remain undocumented**.

**Target:** an *exact discrete* two-species rational recurrence, observable q_(N,j)=a_(N,j)+b_(N,j), separately the global sum Q_N, absolute error zero. This is not a continuum reaction-diffusion or EPANET model, nor a certified physical byproduct prediction. Inputs are exact transport coefficients and initial state, with nonlinear reaction histories treated as unavailable. A one/few-output workload might reuse fixed coefficients, but building a full nonlinear trajectory simply to compute those histories defeats the proposed elimination. The appropriate strongest alternative is a reachability/annihilator nullspace specialist with the same universal reaction-independence guarantee, NOT naive full replay. Falsifier: exhibit a nonzero projection of a reaction channel into the desired terminal local observable after two steps. This cheaper structural screen outranks another ungrounded R-013/014 benchmark.

## Derivation and scope of theorem

Write x_t=(a_t,b_t) in Q^(2D), S=[-I;+I], and use the exact discrete split step

    x_(t+1) = T_t x_t + S r_t(T_t x_t) + u_t,
    T_t = diag(M_A,t,M_B,t),

where r_t is a vector of nonlinear reaction amounts and u_t is an optional KNOWN source. Without linearizing r_t, finite iteration yields the **identity**

    w^T x_N = w^T (T_(N-1)...T_0) x_0
             + Σ_t w^T (T_(N-1)...T_(t+1)) u_t
             + Σ_t w^T (T_(N-1)...T_(t+1)) S r_t(T_t x_t).

Empty products are identities. Stack the linear response columns to arbitrary reaction injections:

    K_N=[S, T_(N-1)S, T_(N-1)T_(N-2)S, ..., T_(N-1)...T_1 S].

For **independently variable arbitrary reaction amounts**, the *linear adjoint formula that never evaluates them* is valid for all histories **iff K_N^T w=0**. Sufficiency follows termwise. Necessity follows by placing an arbitrary reaction impulse in each column. A fixed kinetic law can constrain attainable reaction histories, so the necessity is a statement about **universal rate-independent projection**, not an impossibility theorem for all nonlinear solvers. Time-varying transport is covered by the displayed product. This is standard finite-horizon disturbance-reachability duality, not claimed as an original control theorem.

With constant two-species transport and horizon N=2, w=(u,v) gives

    w^T S=0 ⇒ u=v=c,
    w^T T S=0 ⇒ (M_B-M_A)^T c=0.

For a periodic ring with D=5, M(q)=(1-2q)I+q(L+R), q_A=1/8, q_B=1/4. Hence M_B-M_A=(1/8)(L+R-2I). The connected ring Laplacian has exactly the one-dimensional constant-vector nullspace, so **the only reaction-blind linear output rows are global totals**, even for only two steps. When M_A=M_B, any c works, giving D=5 local composite modes. Independently, the Fourier eigenvalue λ_q(k)=1-2q+2q cos(2πk/D) has equal species values only for zero mode if q_A≠q_B. This is a proved exact-model boundary for the stated class; the R-019 passive invariant remains valid under common transport.
