## Purpose

[R-022](R-022.md) used a DOP853 rtol=1e-12 reference at D=512 without a second reference. This run supplies that check, with the same problem, seed and source as R-022 (probe source and config are byte-identical to R-022's, plus the added reference).

## Result

- rtol=1e-12 reference (25,720 evaluations) vs rtol=1e-11 reference (25,456 evaluations): max-norm difference **4.243e-11**.
- The R-022 test errors were 1.520e-8 (rtol 1e-6), 9.388e-9 (rtol 1e-8), 3.203e-10 (rtol 1e-10). The reference difference is smaller than the smallest of these, so the reference is not what limits the R-022 table at that level.
- Consequence: the reference-to-reference difference is 4.2e-11, well below the R-022 test errors, so for R-022's table the reference is unlikely to be the limiting term. This run does not establish that the reference is within 4.2e-11 of the true solution; that would need the two references to bracket the truth, which is not shown here.

## Limits

- Two-reference agreement is evidence, not proof, that the reference is accurate; it does not bound the reference error rigorously.
- Non-rigorous; costs are against a reference, not an enclosure.
- Single-agent review. No independent reviewer.
