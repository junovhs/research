## Problem, candidate generation, rival and decision gate

**Useful task:** reuse a computed solution to a *discrete nonlinear algebraic* spatial system after one forcing datum changes, when only one output coordinate is queried to absolute error 1e-6. This is not a time-integrated ODE, a continuous PDE, or a statement about Fractodactyl. Workload in this exploratory test: one manufactured exact cached 64-site state; three coefficients, two input-change signs and nine queried distances each, 54 queries total. Input changes and query index are known; successful reuse returns the **unchanged cached coordinate**, not a recomputed state. Rejected queries require a full accuracy-matched solve.

Three distinct candidates were considered *before the probe*: (A) a residual-certified Newton warm restart using the cached state; (B) a locality/inverse-decay admission certificate to return an old component without solving the updated system; and (C) low-rank update/cached factorization (Schur/Woodbury-type) for a linearized solver. Candidate B was selected because it offers a cheap, decisive *mathematical* gate: some remote outputs should provably change by less than 1e-6, while small diagonal dominance should defeat cheap admission. A is the strongest *implemented* correctness comparator, not an established best specialist. An optimized sparse Newton implementation with cached factors and adjoint sensitivity, as well as low-rank updates, could beat B in a realistic workload. Alternative C and R-016's full validated spatial-tail direction were not executed here. This experiment is justified by a potentially transferable computation-elimination question, not because the latest R-card had an unresolved numerical parameter.

**Preselected decision implication:** if no remote queries admit, PARK/CLOSE basic locality admission; if some admit but construction cost or specialist reuse likely dominates, retain only a narrowly costed follow-up, **not** CHALLENGE/confirmation; pursue substantial engineering only after a fair total-cost comparison and novelty clearance.

## Exact model, comparison mathematics and scope

The periodic 64-site system is
```
F_i(x) = a x_i + g x_i^3 - b (x_(i-1) + x_(i+1)) = f_i,
a in {4, 3, 11/5}, b=g=1.
```
Every a>2b. The manufactured exact rational cached state is
`x_i^0 = 1/8 + (((7i) mod 11)-5)/128`; define cached exact forcing `f^0=F(x^0)`. New forcing is `f=f^0 + s*(1/4)*e_0`, sign s=+1 or -1. Query sites are d=0,4,...,32; tolerance `epsilon=1/1000000`. No randomness. The old state is **supplied exactly** without costing its acquisition, and every right-hand side was constructed to make it an exact solution. This is a favorable synthetic condition, not a practical amortization study.

For old root x and new root x', the coordinate differences z=x'-x obey
```
[a + g*((x'_i)^2 + x'_i*x_i + (x_i)^2)] z_i
        - b(z_(i-1)+z_(i+1)) = s*(1/4)*1_(i=0).
```
The diagonal is at least a because g>=0 and the quadratic form is nonnegative. Strong diagonal dominance a>2b gives a unique root (strong monotonicity) and a nonnegative inverse comparison. Writing A for the nearest-neighbor adjacency of the 64-cycle, the vector sensitivity inequality is
```
|z| <= (a I - b A)^(-1) |delta| e_0.
```
A constructive upper vector is obtained from an exact-rational truncated positive walk series
```
v_K = |delta|/a * sum_(k=0)^(K-1) ((b/a) A)^k e_0,
q = 2b/a < 1,
U_K = v_K + [|delta|/a * q^K/(1-q)] * 1.
```
The constant tail is a coordinatewise upper bound to all omitted nonnegative walk terms. The source calculates every term with Python `Fraction`, stops once tail <= epsilon/100, and **independently checks in exact rational arithmetic** that `(aI-bA) U_K >= |delta| e_0` at all sites. The condition `(U_K)_d <= epsilon` is therefore an exact-model admission certificate. It is not a new proof of inverse decay and not a theorem about a general nonsymmetric/nonmonotone nonlinear system. The crude global bound `|delta|/(a-2b)` cannot admit any of these cases.

To independently check observed changed solutions, warm Newton starts at the cached state using SciPy sparse linear solves. Each computed binary64 component is then represented as an **exact rational** and its exact rational residual evaluated against the specified rational equations. With `a>2b`, the residual inequality `||x_new_exact - x_numeric||_inf <= ||F(x_numeric)-f||_inf/(a-2b)` rigorously bounds the numerical root error *for this model*, regardless of Newton stopping heuristics. This is a distinct a posteriori check on the sampled solver, not independent implementation of the locality certificate.

## Scientific challenge, economic limitations and next decision

**Strongest limitation:** the manufactured old root is exact and free, and right-hand sides are derived from it; for a real cached approximate state, its certified error must be added to the admission budget. Constructing U_K currently costs about N*K exact-rational updates: 64*24, 64*43 and 64*196 across a=4,3,11/5 respectively, before output checks. Reusing the same certificate for both signs and multiple output indices amortizes this, but cold construction, memory, reuse count, query mix, rejected queries and fallback have not been timed. The implemented warm Newton counterpart takes 3–5 sparse linear solves and achieves residual-certified errors far below 1e-6, so the **total workload economics are unknown**. There is no measured speedup, industrial workload, production-grade sparse solver, domain-general certificate, or independent scientist/agent review.

**Prior art as ingredient:** exponential inverse decay for banded matrices is well established; see Demko, Moss & Smith, *Decay Rates for Inverses of Band Matrices*, Mathematics of Computation (1984), [primary AMS abstract](https://www.ams.org/journals/mcom/1984-43-168/S0025-5718-1984-0758197-9/) and [DOI](https://doi.org/10.1090/S0025-5718-1984-0758197-9); Nabben (1999), [DOI](https://doi.org/10.1137/S0895479897317259). The lattice comparison uses known nonlinear monotonicity and positive Neumann series; its combination has **NOVELTY UNVERIFIED**, with no presumptive originality.

**Self-review only, not independent challenge:** correctness relies on strong diagonal dominance, positive cubic coefficient, exact old cached state, single-site forcing delta and exact rational comparison; near a<=2b the guard *does not apply*. General nonmonotone dynamics may amplify changes. Rejected queries must use a guarantee-matched fallback. The result alone does not justify an edge in MAP.md: the study shifts computational task but shows no economically meaningful new mechanism independent of known matrix inverse decay, no enabling verified novel result, no definitive closure of the previous lineage.
