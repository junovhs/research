# Experiments

One directory per actual investigation. Start from template.json, but do not submit an empty template as evidence.

Keep a small specification, input/query manifest, code/configuration reference and result summary. Larger attempted-probe ledgers and cached observations stay outside Git with hashes and retrieval/reconstruction instructions.

Record negative and failed runs. Keep the reason for rejecting or parking a lead brief. Use issues only for work that benefits from tracking; do not create one issue per numerical probe.

There are no completed experiments in this directory yet.
